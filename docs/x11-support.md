# X11 support matrix

This matrix describes implemented features, not full ICCCM, EWMH, RandR, or XKB compliance. Test references identify exercised behavior, not exhaustive protocol coverage.

| Protocol and feature | Current implementation | Test coverage and limitations |
| --- | --- | --- |
| ICCCM: window lifecycle | Manages mapped and eligible existing root children; ignores override-redirect windows. Sets `WM_STATE` to Normal, Iconic, or Withdrawn as appropriate. Handles initial iconic `WM_HINTS`, `WM_CHANGE_STATE` to Iconic, and remapping iconic windows. | `tests/x11.rb` and `tests/client.cpp` exercise existing windows, iconic state, withdrawal, restart, and shutdown. This is not a complete lifecycle or session-management implementation. |
| ICCCM: input focus | Reads the input flag in `WM_HINTS`; sends `WM_TAKE_FOCUS` when listed in `WM_PROTOCOLS`. Focus follows pointer entry and is restored on workspace changes. | `tests/client.cpp` exercises the four input/take-focus combinations, pointer focus, and workspace focus restoration. Other focus interactions are not comprehensively tested. |
| ICCCM: size and configure | Applies valid `WM_NORMAL_HINTS` minimum, maximum, base, resize increment, and aspect values within the tile when possible. Managed configure requests receive a synthetic `ConfigureNotify`; unmanaged requests are forwarded. | `tests/size-hints.cpp` covers selected calculations; `tests/client.cpp` exercises geometry. Conflicting or impossible hints may fall back to tile-limited sizes. Other ICCCM hints and protocols are not generally implemented. |
| EWMH: WM identity | Publishes `_NET_SUPPORTED`, `_NET_SUPPORTING_WM_CHECK`, and a supporting window with `_NET_WM_NAME` set to `mortar`. Advertises five atoms: `_NET_NUMBER_OF_DESKTOPS`, `_NET_CURRENT_DESKTOP`, `_NET_WM_DESKTOP`, `_NET_SUPPORTING_WM_CHECK`, and `_NET_WM_NAME`. | `tests/client.cpp` checks the supporting-window relationship; `tests/x11.rb` checks selected startup and shutdown state. This list is not a claim of complete EWMH support. |
| EWMH: desktops | Publishes ten desktops and the current desktop. Sets each managed window's `_NET_WM_DESKTOP`; handles requests to change the current desktop or move a window. Restores valid stored desktop values during startup. | `tests/client.cpp` exercises desktop properties, requests, focus, and restart. Only indices 0–9 are accepted; special desktop values and other EWMH features such as client lists, active-window requests, and window types are not implemented. |
| RandR: screen changes | Requires the RandR extension and listens for screen-change notifications; updates the single tiling area's width and height. | `tests/x11.rb` tests startup failure when RandR is unavailable and preservation of an existing window. Screen-change handling is implemented but no dedicated resize test was found. Output discovery, per-output workspaces, and multi-monitor layout are not implemented. |
| XKB: workspace keys | Uses the core XKB keyboard and xkbcommon keymap to resolve digit keysyms, groups, levels, and modifiers. Alt plus digit switches workspace; an additional Shift moves the focused window, or Control when Shift is required to produce the digit. Ignores detected lock modifiers and reloads on keyboard or map changes. | `tests/x11.rb` and `tests/client.cpp` exercise key grabs, remapping, French layout, and group changes. `tests/keyboard.cpp` exercises mapping, lock handling, shifted and other level modifiers, and reload. Missing XKB, an unavailable Alt modifier, or conflicting grabs can prevent startup. |
| XKB: additional bindings | Scheme can register keysym/modifier callbacks. Failed key-grab replacement retains the previous grabs. | `tests/keyboard.cpp` exercises replacement, reload, failure, and removal; `tests/x11.rb` exercises a Scheme binding. |

The integration harness uses Xvfb and XTEST. Its scenarios cover a subset of behavior, not interoperability with every X server, client, keyboard map, or protocol feature. Source: `mortar/main.cpp` and `mortar/keyboard.cpp`; tests: `tests/x11.rb`, `tests/client.cpp`, `tests/keyboard.cpp`, and `tests/size-hints.cpp`.
